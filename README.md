# Folio

광고 없는 문서 뷰어 웹앱: **https://euhaan.github.io/folio/**

한글, 엑셀, 워드, 파워포인트, PDF, 웹 문서, 그림, 텍스트, ZIP 파일을 기기 안에서만 열어 보여 주고,
받아 둔 언어(한국어·영어·일본어·중국어) 사이에서 기기 안에서 번역합니다.
이 저장소(`gh-pages` 브랜치)에는 웹앱의 **배포 파일만** 들어 있습니다.

## 고지

본 제품은 한컴의 HWP 문서 파일(.hwp) 공개 문서를 참고하여 개발하였습니다.

ᄒᆞᆫ글, 한글, 한컴, HWP, HWPX는 ㈜한글과컴퓨터의 상표 또는 등록상표입니다.
Microsoft, Word, Excel, PowerPoint는 Microsoft Corporation의 상표 또는 등록상표입니다.
iPhone, Safari는 Apple Inc.의, Android, Chrome은 Google LLC의, 카카오톡은 ㈜카카오의, GitHub는 GitHub, Inc.의 상표입니다. 그 밖의 회사명과 제품명은 각 소유자의 상표입니다.
Folio는 위 회사들과 제휴, 후원, 승인 관계가 없는 독립 앱이며, 상표는 지원하는 파일 형식과 사용 환경을 설명하기 위해서만 사용합니다.

## 개인정보

Folio는 개인정보를 수집하지 않습니다. 문서는 기기 안에서만 열리며 어디로도 전송되지 않습니다.
사용자가 "최근 파일 기억"을 켠 경우의 최근 파일과, 읽던 자리·책갈피(알아볼 수 없는 표식)만 그 기기 안에 저장됩니다.
광고, 분석, 추적 도구를 사용하지 않습니다. 웹앱 파일은 GitHub Pages에서 제공되며,
이때의 접속 기록은 GitHub가 자체 개인정보 처리방침에 따라 처리할 수 있습니다.
웹앱은 같은 계정의 다른 GitHub Pages 사이트와 주소(euhaan.github.io)를 함께 씁니다.
번역은 기기 안에서 합니다. 사용자가 설정에서 고른 언어의 번역 모델만
[folio-models](https://github.com/Euhaan/folio-models)에서 받고, 문서 내용은 보내지 않습니다.

## 면책

Folio는 무료로 "있는 그대로" 제공되며 문서 표시의 정확성이나 완전성을 보증하지 않습니다.
중요한 문서는 원본 프로그램으로 다시 확인해 주세요.
